# eva

## Bardapure Productions

A React + Vite single-page creative-agency demo with a scroll-led narrative, responsive creator and brand portals, animated proof points, and a deferred Three.js accent.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

The site is published to GitHub Pages at https://justbloomteamco2.github.io/eva/.

## Demo interactions

- The creator portal includes 13 sample registration fields; the brand portal is a separate contact form.
- Both forms open a "Coming Soon" dialog instead of submitting data.
- Portfolio, testimonials, metrics, and the Instagram preview use sample content.
- The 3D service-card accent loads when approached on desktop and is omitted on mobile.
